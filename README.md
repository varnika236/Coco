 🐾 Coco — Animal Rescue & Safety App

Coco is a **prototype web application concept for animal rescue and safety**. The project explores how a simple digital platform could encourage people to report animals in need and participate in animal welfare activities.

The current version focuses mainly on the **frontend experience, page flow, UI design, and core concept demonstration**.

## 🌐 Live Demo

🚀 **[View Coco Live](https://coco-animalrescueapp.netlify.app/)**

## 💡 Idea Behind Coco

Many stray and injured animals need help, but people may not know how or where to report them.

Coco is designed around the idea of making that process simpler by providing a platform where users can:

* Discover the purpose of the application
* Enter their basic information
* Explore animal rescue-related options
* Capture animal-related information through the camera interface
* Explore a reward-based concept
* View a certificate concept for participation

> **Note:** Coco is currently a prototype created to demonstrate the concept and user experience. Some features are UI demonstrations and are not yet connected to a complete production backend.

## ✨ Current Features

### 🐾 Welcome & Introduction

A dedicated welcome page introduces users to the Coco platform and its purpose.

A camera page is included as part of the proposed animal-reporting workflow.

A reward page demonstrates how users could potentially be encouraged to participate through a reward system.

### 🏆 Certificate Concept

A certificate page demonstrates how user contributions could eventually be recognized.

The project contains informational pages explaining the purpose and concept of Coco.
